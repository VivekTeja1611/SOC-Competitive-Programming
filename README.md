# SOC Competitive Programming

This repository tracks my journey through the **Summer of Code (SOC)** Competitive Programming initiative at **IIT Bombay**. The SOC program provides structured learning paths with dedicated mentorship, focusing on mastering algorithmic problem-solving techniques through guided practice.

**Mentors:** Harshul Suthar, Prabhav Khandelwal, Saksham Saharia, Devang Tibrewal

## 🧠 What I've Learned So Far

### ✅ Problem-Solving Techniques:
- **Greedy Algorithms**: Learned how to approach problems by making locally optimal choices (e.g., activity selection, coin problems)
- **Two Pointers & Sliding Window**: Efficiently handling subarrays and ranges for sum or frequency problems
- **Prefix Sums**: Applied for quick range queries on arrays
- **Binary Search**: Used both iterative and recursive versions on sorted arrays and applied to search space problems
- **Sorting Techniques**: Importance of custom sorting using comparators in C++

### ✅ Data Structures:
- **Vectors and Arrays**: Manipulated efficiently using STL functions
- **Sets and Maps (STL)**: For handling unique elements and key-value associations
- **Stacks and Queues**: Applied in classic problems like Next Greater Element
- **Priority Queues**: Used in greedy and shortest path scenarios

### ✅ Dynamic Programming (DP):
- Solved basic DP problems involving:
  - Fibonacci numbers
  - 0/1 Knapsack
  - Longest Increasing Subsequence (LIS)
  - DP on Grids
  - Edit Distance and advanced DP optimizations

### ✅ Graph Algorithms:
- Basic understanding of:
  - DFS and BFS
  - Cycle detection
  - Connected components
  - Intro to Dijkstra's algorithm

### ✅ Number Theory & Advanced Topics:
- **Modular Exponentiation**: Fast exponentiation under modulus using divide-and-conquer
- **Divisor Summation**: Efficient divisor summation using multiples and nested loops
- **Combinatorics**: Using modular arithmetic with factorials and inverses
- **Bit Manipulation**: Use binary operations for compact logic and speed

### ✅ Coding Skills:
- Improved speed and accuracy in writing and debugging C++ code
- Practiced reading constraints carefully and optimizing accordingly

## 📅 Weekly Breakdown

### Week 1: Core Logic & Setup
**Problems Solved:** Missing Number, Repetitions, Coins, Lucky Numbers, Weird Algorithm  
**Focus:** Iteration & Conditionals, Prefix Sums, Greedy Thinking, Sequence Simulation

### Week 2: Sorting, STL & Sliding Techniques  
**Problems Solved:** Playlist, Sum of Two Values, Sum of Three Values, Sliding Window Maximum, Stick Lengths  
**Focus:** STL Algorithms & Containers, Two Pointers, Sliding Window, Hash Maps, Median Logic

### Week 3: Greedy, DP & Advanced Techniques
**Problems Solved:** Movie Festival, Factory Machines, Coin Combinations I, Edit Distance, Dice Combinations, Tasks and Deadlines, Projects  
**Focus:** Greedy Algorithms, Dynamic Programming, Amortized Analysis, Bit Manipulation

### Week 4: Number Theory & Combinatorics
**Problems Solved:** Modular Exponentiation, Sum of Divisors  
**Focus:** Modular Exponentiation, Number Theory Foundations, Combinatorics
