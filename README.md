# SOC Competitive Programming

This repository tracks my journey through the **Summer of Code (SOC)** Competitive Programming initiative at **IIT Bombay**. The SOC program is a comprehensive skill development initiative that provides structured learning paths with dedicated mentorship. This competitive programming track focuses on mastering algorithmic problem-solving techniques through guided practice and real-world applications.

**Mentors:** Harshul Suthar, Prabhav Khandelwal, Saksham Saharia, Devang Tibrewal

Each week focuses on both **learning key concepts** and **solving problems** that apply them.

The structure includes:

- 📘 Guided readings from the _Competitive Programmer's Handbook_ and CS101 resources  
- 💻 Hands-on coding practice  
- 🧠 Application of algorithmic techniques in C++

## ✅ Week 2: Sorting, STL & Sliding Techniques

**📘 Read:**
- Competitive Programmer's Handbook Chapters 4 & 5
- Guide to competitive Programming Chapters 4, 5, 8

**🧠 Concepts Covered:**
- **STL Algorithms & Containers**: Efficient use of `sort()`, sets, maps, and binary search utilities.
- **Two Pointers**: Maintain two indices to scan efficiently (useful in sorted arrays).
- **Sliding Window**: Track a moving subarray or range in constant or amortized time.
- **Hash Maps**: Fast key-value lookups, especially useful in sum and frequency problems.
- **Median Logic**: Choosing the middle value to minimize total absolute deviation.

## ✅ Week 3: Greedy, DP & Bitwise Prep

**📘 Read:**
- Competitive Programmer's Handbook Chapters 6–8, 10

**🧠 Concepts Covered:**
- **Greedy Algorithms**: Solve problems by making the best choice at each step.
- **Dynamic Programming (DP)**: Solve problems by breaking them into overlapping subproblems and caching results (LIS).
- **Amortized Analysis**: Average cost per operation over a sequence (e.g., stack, queue usage).
- **Bit Manipulation**: Use binary operations for compact logic and speed (e.g., toggling bits, subsets).
